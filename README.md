# Wieżostraż / Towerguard

3D medieval tower defense in the browser (Three.js r128, no bundler, no build).
Defend the tower from four directions: orcs, goblins, thieves, wargs, dark elves, mages, three kinds of dragons.
Hire helpers with Shift+1–9, play in Polish or English (L key), Monty Python and friends voice the chaos.

**Play online: https://grgzx.github.io/towerguard/**

Or open `index.html` locally in a browser. Controls: WASD move, mouse aim, LMB fire, 1–9 weapons and spells,
R/T/Y repair and upgrades, Shift+1–9 hire a helper, M voices, L language, P pause.

See `CONTEXT.md` for the code structure (Polish).
